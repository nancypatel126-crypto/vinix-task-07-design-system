
# Nexora Design System

## Project Overview
Nexora is a reusable UI Design System created for VINIX Internship Task 7.

It provides consistent design elements and reusable components for modern web applications.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Key Features
- Color Palette
- Typography System
- Reusable Buttons
- Profile Cards
- Form Components
- Status Badges
- Spacing System
- Dark and Light Theme
- Responsive Layout
- Form Validation

## Project Structure
- index.html
- style.css
- script.js
- README.md
- assets/images/

## How to Run
1. Clone the repository.
2. Open the folder in VS Code.
3. Open index.html using Live Server.
